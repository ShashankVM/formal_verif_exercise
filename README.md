## About
This is a Formal Verification exercise using HW-CBMC.

# Installation
Please install by running `sudo ./install.sh`.

## Prerequisites: 
- Basic Verilog and Digital Design.
- Familiarity with the use of a text editor such as VSCode or Vim.

## Learning outcomes: 
- Use open-source tools to find bugs in industrial designs.
- Explore design behaviour using HW-CBMC without a single simulation.
- Understand the application of formal techniques in hardware verification.
